💻 Meu Blog Tech

Um blog desenvolvido em HTML, CSS e JavaScript para praticar conceitos básicos de desenvolvimento web.

O projeto permite criar várias postagens, interagir com os botões de reação e alternar entre os temas claro e escuro.

🚀 Funcionalidades
📰 Exibição de múltiplos posts
❤️ Botão de curtida
👍 Botão de reação
🔄 Possibilidade de curtir e remover a curtida
🌙 Alternância entre tema claro e tema escuro
✨ Transição suave entre os temas
🎨 Variáveis CSS para facilitar a personalização
📦 Cards de posts com box-shadow
📱 Layout responsivo para dispositivos móveis
🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript
🖥️ Como executar
Baixe ou clone este repositório.
Abra o projeto no navegador através do arquivo index.html.
Teste os botões de reação.
Clique no botão de tema para alternar entre o modo claro e escuro.

Não é necessário instalar nenhuma dependência.

🌙 Tema escuro

O projeto possui um sistema de troca entre tema claro e tema escuro.

A troca é feita através de JavaScript e da classe .tema-escuro.

❤️ Sistema de curtidas

Os botões de reação possuem contadores individuais.

É possível clicar no botão para adicionar uma curtida e clicar novamente para remover.

O JavaScript utiliza forEach() para fazer os botões funcionarem em todos os posts.

🎨 Melhorias visuais

Foram adicionadas sombras aos artigos para criar um visual mais moderno e dar profundidade aos cards.

Também foram utilizadas transições suaves para melhorar a troca entre os temas.

📱 Responsividade

O blog foi adaptado para funcionar em diferentes tamanhos de tela, incluindo computadores, tablets e celulares.
